# 小白短视频剪辑工作流

这是自包含的 macOS 优先技能。内含执行工具；不需要安装其他技能才能剪片。WorkBuddy 负责理解内容和挑选镜头，FFmpeg 负责确定性剪辑，faster-whisper 可选负责本地转录。不要把只有脚本/方案的结果说成已完成视频。

## 接住用户的一句话

已给出素材和目标时直接开始。默认：中文口播/访谈、目标约 60 秒、1080×1920、30fps、保留原声、白字黑描边字幕、无背景音乐、不发布。横片默认完整画面加背景留边，避免切掉另一位受访者；只有画面审核支持或用户要求才用填满裁切。

缺素材时只要求上传视频或提供本地路径。没有内容目标时可依据转录自行给出有完整信息的一段；不要让小白填写时间码、JSON 或工具参数。长访谈优先先转录、再选主题，不要机械取前 60 秒。默认只做一条；用户要多条时给每条独立清单和版本目录。

## 执行与调用库

先确定当前技能目录为 `SKILL_DIR`，工具入口是相对于本文件的 `scripts/video.py`。不要沿用作者电脑的绝对路径。
找可执行 Python 3.9+：优先宿主已配置的 Python，否则 `python3`。运行 `"<PY>" "<SKILL_DIR>/scripts/video.py" doctor`；读取结果而非仅看退出码。依赖缺失按 [setup.md](references/setup.md) 修复，禁止把失败包装成成功。

按需读以下模块；这些模块是本包的调用库，无需子代理功能：

| 模块 | 何时调用 | 输入 → 输出 |
|---|---|---|
| 素材检查 | 每次开工 | 本地视频 → `probe` 元信息、关键帧 |
| 转录与选段 | 没有准确文字时间轴 | `transcribe` → 转录、词级时间码；按 [editing.md](references/editing.md) 选完整观点 |
| 删停顿 | 用户要紧凑或口播空白很多 | `silence` → 候选保留区间；结合词级时间码审核 |
| 字幕 | 有语音且要求字幕 | `captions` 按词级时间码拆句 → SRT、纠错、选择 source/output 时间轴 |
| 合成导出 | 已有有效清单 | `validate`、`render` → MP4、SRT、实际剪辑清单、机器检查 |
| 交付检查 | 渲染后 | `quality` 抽帧、完整解码 + 视觉和听感审核 |
| 配音/图片扩展 | 用户要求文章或幻灯片变视频 | [extensions.md](references/extensions.md)，先取得图像和配音再合成 |

所有命令、参数和清单格式见 [engine.md](references/engine.md)。使用 subprocess 参数数组或宿主安全的文件/命令调用，路径含中文、空格、引号时也不能拼接成未转义 shell 命令。核心剪辑需要本地 Python 和 FFmpeg；不需要在线视频服务。有用户提供的字幕或选段时可以跳过转录模型直接导出。

## 内容与字幕约束

先看至少开头、选段中间与结尾画面，确认人脸、画面方向、文字和音轨。转录不代表看过画面。
选段要交付一个听得懂的观点，保留限定词、否定词、论据和说话者身份。不要把跨段拼接伪装成原话，也不要用静音检测猜精彩片段。短到目标时长会破坏意思就略长并解释。

`silence` 的结果是建议，不可直接删除所有停顿；在词首/词尾外留缓冲，句间停顿不要全删。原始转录可能一段很长，烧字幕前用词级时间码拆为通常 10–18 个中文字、最多两行；不能按字数猜语音时间。只有整句时间码时保留句子时间或要求更精细转录，不声称词级对齐。交叉剪辑后把 source 字幕映射到输出轴，多素材必须使用 output 字幕。

人名、数字、术语以音频和用户词表校对。保留原意；不主动补写说话者没有说过的话。默认字幕放在画面约 78% 高度、宽度不超过 78%，这是通用留白，仍需结合平台 UI 和人脸位置检查。

## 可恢复工作与交付

新建项目目录，原素材只读。记录 `brief.md`（需求与默认值）、`edit-rationale.md`（选段原因/删除原因/原片时间码）、`edit-plan.json`（可重跑清单）。每次渲染用新的 `out-vN`。失败时保留诊断，最多针对明确原因修复两次；还失败就给出具体阻塞及可用中间产物。

渲染返回的 `machine_pass` 必须为 true 才能说编码和解码检查通过。打开 `review` 抽帧看字幕、脸和黑边；听开头、连接处和结尾，检查音画同步、截字、音量。机器无法判断语义或字体缺字；未查看或未听的项在交付说明中标为待验收，不得全部勾为通过。有条件再提交 `quality.json` 的人工检查结论与证据。

交付：`final.mp4`、`subtitles.srt`（要求字幕时）、`edit-plan.json`、`edit-rationale.md`、`quality.json`。给用户可点击路径及一句结果；附标题/简介属于可选文案服务，不能替代成片。

本地剪辑默认不上传素材。模型首次下载会访问模型托管网站，应说明体积和离线替代；文字在线配音会发送文案，要先取得这一次内容发送授权。不能未经授权调用付费服务、克隆音色或自动发布。分享技能时只分享包本身，别打包私有素材、密钥、转录或个人字体。
