下载完整领取包 ZIP仅下载技能安装包

请在 Windows 电脑上下载。完整包内有技能 ZIP、备用 ZIP、安装引导与测试任务。

三步开始

1 · 下载并导入解压完整领取包，只把里面的「技能安装 ZIP」上传到 Workbuddy 的技能管理并启用。导入器要求带文件夹结构时，用文件名含 folder 的备用 ZIP。
2 · 让 Workbuddy 检查环境把领取包里的「Windows测试任务.txt」发给 Workbuddy。它会先检查电脑现有环境，缺依赖时给出下载和安装指引，补齐后复检。
3 · 提供一段口播试剪环境和合成测试通过后，提供 30–120 秒的口播。查看 MP4 与字幕，并试听剪辑接缝。

安装时遇到问题？

先看Windows 用户安装引导。这份说明覆盖复用 Workbuddy 自带 Python、把 FFmpeg 放进技能 bin 目录、网络较慢时选择一次性镜像，以及模型下载后的复检。

本包处于 Windows 测试阶段。32 项本地检查已通过；Windows 客户端导入、PowerShell 环境检测和真实视频出片，仍以你的实机测试结果为准。
