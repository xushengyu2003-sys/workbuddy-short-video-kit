第一次使用为什么比较久？

首次可能需要准备 Python、FFmpeg、字幕依赖和语音识别模型。让 WorkBuddy 按技能说明检查并提示处理。后续同一素材可复用转录；新版保存底片，只改字幕可省去重剪和混音。

Windows 能用吗？

目前 macOS 已实测。Windows 尚未实机验收，现阶段不宣传 Windows 一键即用。

需要付费接口吗？

核心剪辑和转录采用本地工具，不要求视频 API Key。WorkBuddy 本身的模型使用或订阅按平台规则计费。外部生成服务只有你明确选择时才考虑使用。

机器检查通过，就是完全剪好了吗？

机器检查确认文件可解码、尺寸与时长正常。字幕识别可能有错，删减也需要核对原意，发布前请听看成片。

安装失败怎么办？

先确认导入的是技能安装 ZIP，不是源码 ZIP 或外层领取包。仍失败时，可以从 备用下载目录 获取文件名含 folder 的安装包，并把错误提示发给 WorkBuddy。
